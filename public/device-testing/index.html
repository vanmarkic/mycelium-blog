Device Testing

Detects media device plug / unplug two ways at once — the devicechange event and an independent enumerateDevices() poll — so you can tell whether the event is broken or the devices genuinely aren't changing.

Environment

Labels stay empty until an origin has an active camera/mic grant. Empty labels with granted permission usually means the grant isn't actually live for this origin.

Controls

ms
Some Linux/Chromium builds only deliver devicechange after a getUserMedia call has happened in the page's lifetime. Holding the stream open (checkbox above) is a further test — if events fire only while a stream is live, that's the media layer, not your listener.

Verdict

Plug or unplug a device to collect evidence.
