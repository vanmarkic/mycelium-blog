## Key Learnings

**State Persistence with History Management**

Loyer.brussels implements sophisticated state persistence that maintains form history across navigation. The GlobalFormProvider pattern ensures state survives page transitions while supporting undo/redo functionality.

**Next.js SSG for Public Services**

Using Next.js's static generation for a Brussels rent calculation tool ensures fast load times and SEO optimization while maintaining interactive form functionality. This pattern is ideal for public service tools that need both discoverability and rich UX.

**Radix UI Component Integration**

The project demonstrates effective use of Radix UI primitives (like `@radix-ui/react-switch`) with custom styling via Tailwind CSS. This provides accessible, well-tested components without sacrificing design flexibility.

## Technical Deep Dive

### Global State Architecture

The GlobalFormProvider pattern centralizes form state management:

```typescript
interface FormState {
  currentStep: number;
  data: Record<string, any>;
  history: FormState[];
  canUndo: boolean;
  canRedo: boolean;
}

interface GlobalFormProvider {
  state: FormState;
  updateField: (field: string, value: any) => void;
  nextStep: () => void;
  prevStep: () => void;
  undo: () => void;
  redo: () => void;
}
```

This architecture enables complex multi-step forms with history tracking and state persistence across page reloads.

### Navigation Controls Refactoring

Recent commits removed unnecessary history state updates in NavigationControls, simplifying the state flow. This demonstrates the value of continuous refactoring to reduce complexity as requirements become clearer.

### Testing Strategy

The test suite emphasizes state persistence edge cases:

- Loading state handling during persistence
- History synchronization across providers
- Data integrity during navigation

TDD caught several race conditions between form updates and history persistence that would have been difficult to debug in production.

## Conclusion

Loyer.brussels showcases how Next.js SSG, TDD, and sophisticated state management combine to create reliable public service tools. The state persistence architecture ensures users never lose progress, while the static generation provides the performance and SEO benefits essential for government services.
