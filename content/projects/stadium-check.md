# Stadium Check - Base de Données Sportive

## À propos du projet

Stadium Check est une base de données collaborative sur les stades et infrastructures sportives. Le projet vise à centraliser et vérifier les informations sur les équipements sportifs à travers le monde.

## Notre vision

Les données sportives sont souvent fragmentées et peu fiables. Stadium Check crée une source unique de vérité, maintenue par la communauté et vérifiée régulièrement.

## Besoins financiers

Pour maintenir et étendre la base de données, nous avons besoin de:

- **2 500 € /an** pour l'infrastructure et le stockage
- API et services de géolocalisation
- Vérification des données
- Développement de l'interface

### Répartition du budget

- 35% : Infrastructure et stockage
- 30% : Services API
- 25% : Développement

## Ce que votre soutien permet

En soutenant Stadium Check, vous contribuez à:

- Créer une base de données fiable et open source
- Faciliter l'organisation d'événements sportifs
- Améliorer l'accessibilité de l'information sportive
- Développer des outils pour les analystes sportifs
